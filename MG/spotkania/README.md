## Proponowany rytm

1. S01 (obowiązkowy początek).
2. Jedna rozmowa (S02 albo S04).
3. Jedna naprawa (S05, S06 albo kotłownia z S08).
4. Jedna lekka walka.
5. Druga naprawa.
6. S07 jako finałowy pościg.
7. Trzecia naprawa i epilog.

Nie musisz rozegrać wszystkich spotkań. Liczy się swoboda graczy, a nie odhaczanie listy.
