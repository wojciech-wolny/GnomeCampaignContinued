# Złoty posąg, fałszywe brody i przeciek

Przygoda na jedną sesję do Pathfindera (1. edycja), osadzona w podwodnej gnomiej akademii magii.  
Ton: komedia technicznej katastrofy. Wszystkie materiały są po polsku. Przy opisach czarów i atutów w kartach postaci podano w nawiasie oryginalną nazwę z podręcznika, żeby łatwo je odszukać.

**Poziom postaci:** 3 · **Gracze:** 4–5 · **Czas gry:** 3–4 godziny

---

## Podział materiałów

| Folder | Dla kogo | Zawartość |
|---|---|---|
| **[MG/](MG/README.md)** | Mistrz Gry | plan sesji, zagadki z rozwiązaniami, spotkania, bohaterowie niezależni, historia świata, mapa z oznaczeniami |
| **[gracze/](gracze/README.md)** | Gracze | wprowadzenie, mapa bez tajemnic, rekwizyty, karty postaci |

**Nie mieszaj folderów przy stole.** Gracze dostają wyłącznie zawartość folderu `gracze/`.

---

## Szybki start

1. Gracze czytają `gracze/brief.md` i wybierają postacie z `gracze/postacie/`.
2. MG czyta `MG/plan-sesji.md` i przygotowuje zegar powodzi (6 pól).
3. Rekwizyty z `gracze/rekwizyty.md` wręczasz wtedy, gdy wskazuje na to scenariusz (`MG/rekwizyty-kiedy.md`).
4. Spotkania znajdziesz w `MG/spotkania/`.
5. Do druku otwórz [`druk/index.html`](druk/index.html).
