## Co wiecie o lokacjach na start

| Miejsce | Notatka z dyżuru |
|---|---|
| Atrium | posąg, kopuła, główny hol |
| Dyżurka | klucze, panel alarmowy, herbata profesora Plinka |
| Biblioteka | schematy i szepcząca bibliotekarka Vellum |
| Magazyn kryształów | zapasy awaryjne, drzwi z zamkiem na suwaki |
| Korytarz B | rury i plakaty BHP z twarzą Tib |
| Pokój gościnny | kwatera „wymiany studenckiej” |
| Wieża Pieczęci | tablica ciśnienia i Wielki Czerwony Przycisk |
| Kanały i kotłownia | przewody, wilgoć, chochliki serwisowe |
| Pod atrium | przestrzeń pod posadzką atrium, właz serwisowy |
| Szyb transportowy | winda towarowa |

## Zasada przy stole

Nie wiecie jeszcze, **co dokładnie się zepsuło**.  
Szukajcie, łatajcie i wypytujcie bohaterów niezależnych — MG będzie odsłaniał szczegóły w trakcie gry.
