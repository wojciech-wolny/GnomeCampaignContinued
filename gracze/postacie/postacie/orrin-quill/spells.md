# Orrin Quill — opisy czarów

[← Wróć do karty](sheet.md)

Oznaczenia: W — komponent werbalny, S — somatyczny, M — materiałowy, O — skupienie, BS — boski symbol. „(odw.)” przy czasie działania oznacza, że czar można odwołać.  
Zasięg bliski: 25 stóp + 5 stóp na 2 poziomy (przy 3. poziomie: 30 stóp). Daleki: 400 stóp + 40 stóp na poziom (520 stóp).

---

## Czary czarodzieja

### Wykrycie magii

*Nazwa w podręczniku: Detect Magic*

| | |
|---|---|
| **Szkoła** | poznanie |
| **Krąg** | czarodziej/zaklinacz 0 |
| **Czas rzucania** | 1 akcja standardowa |
| **Komponenty** | W, S |
| **Zasięg** | 60 stóp |
| **Obszar** | stożek |
| **Czas działania** | koncentracja, do 1 minuty na poziom (odw.) |
| **Rzut obronny** | brak |
| **Odporność na czary** | nie |

Wykrywasz magiczne aury. W 1. rundzie: czy są obecne. W 2. rundzie: ile ich jest i która jest najsilniejsza. W 3. rundzie: siła, położenie i szkoła każdej aury (test Wiedzy (magia)).

*Zawsze przed dotknięciem czegoś, co brzęczy, świeci albo ma tabliczkę „nie dotykać”.*
