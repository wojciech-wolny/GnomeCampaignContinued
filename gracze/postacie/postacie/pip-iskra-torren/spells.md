# Pip „Iskra” Torren — opisy czarów

[← Wróć do karty](sheet.md)

Oznaczenia: W — komponent werbalny, S — somatyczny, M — materiałowy, O — skupienie. „(odw.)” przy czasie działania oznacza, że czar można odwołać.  
Zasięg bliski: 25 stóp + 5 stóp na 2 poziomy (przy 3. poziomie: 30 stóp). Średni: 100 stóp + 10 stóp na poziom (130 stóp).

## Czary czarodzieja

### Tańczące światła

*Nazwa w podręczniku: Dancing Lights*

| | |
|---|---|
| **Szkoła** | wywoływanie [światło] |
| **Krąg** | czarodziej/zaklinacz 0 |
| **Czas rzucania** | 1 akcja standardowa |
| **Komponenty** | W, S |
| **Zasięg** | średni |
| **Efekt** | do czterech świateł w promieniu 10 stóp |
| **Czas działania** | 1 minuta (odw.) |
| **Rzut obronny** | brak |
| **Odporność na czary** | nie |

Tworzysz do czterech świateł, które poruszają się zgodnie z twoją wolą w zasięgu czaru.

*Oświetlają kanały; można nimi udawać latarnie patrolu.*

### Magiczny pocisk

*Nazwa w podręczniku: Magic Missile*

| | |
|---|---|
| **Szkoła** | wywoływanie [moc] |
| **Krąg** | czarodziej/zaklinacz 1 |
| **Czas rzucania** | 1 akcja standardowa |
| **Komponenty** | W, S |
| **Zasięg** | średni |
| **Cele** | do pięciu istot, z których żadne dwie nie stoją dalej niż 15 stóp od siebie |
| **Czas działania** | natychmiastowy |
| **Rzut obronny** | brak |
| **Odporność na czary** | tak |

Każdy pocisk trafia automatycznie i zadaje 1k4+1 obrażeń od mocy. Na każde dwa poziomy rzucającego powyżej 1. dostajesz dodatkowy pocisk (przy 3. poziomie: 2 pociski). U Pipa jeden z pocisków zadaje +1 ze Wzmożonych czarów (premia nie mnoży się na każdy pocisk).

*Nigdy nie chybia. Nawet gdy cel ucieka szybciej niż Zizzle przed rachunkiem.*

*Ktoś ucieka korytarzem? Już nie. Klasyka.*
