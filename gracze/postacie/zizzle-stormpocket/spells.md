# Zizzle Stormpocket — opisy czarów

[← Wróć do karty](sheet.md)

Oznaczenia: W — komponent werbalny, S — somatyczny, M — materiałowy, O — skupienie. „(odw.)” przy czasie działania oznacza, że czar można odwołać.  
Zasięg bliski: 25 stóp + 5 stóp na 2 poziomy (przy 3. poziomie: 30 stóp). Średni: 100 stóp + 10 stóp na poziom (130 stóp). Daleki: 400 stóp + 40 stóp na poziom (520 stóp).  
Dzięki atutowi Pominięcie komponentów Zizzle nie potrzebuje tanich komponentów materiałowych.

## Czary zaklinacza

### Wykrycie magii

*Nazwa w podręczniku: Detect Magic*

| | |
|---|---|
| **Szkoła** | poznanie |
| **Krąg** | czarodziej/zaklinacz 0 |
| **Czas rzucania** | 1 akcja standardowa |
| **Komponenty** | W, S |
| **Zasięg** | 60 stóp |
| **Obszar** | stożek |
| **Czas działania** | koncentracja, do 1 minuty na poziom (odw.) |
| **Rzut obronny** | brak |
| **Odporność na czary** | nie |

Wykrywasz magiczne aury. W 1. rundzie: czy są obecne. W 2. rundzie: ile ich jest i która jest najsilniejsza. W 3. rundzie: siła, położenie i szkoła każdej aury.

*Zawsze przed dotknięciem czegoś, co brzęczy, świeci albo ma tabliczkę „nie dotykać”.*

### Barwny strumień

*Nazwa w podręczniku: Color Spray*

| | |
|---|---|
| **Szkoła** | iluzja (wzór) [wpływający na umysł] |
| **Krąg** | czarodziej/zaklinacz 1 |
| **Czas rzucania** | 1 akcja standardowa |
| **Komponenty** | W, S, M (czerwony, żółty i niebieski proszek albo kolorowy piasek) |
| **Zasięg** | 15 stóp |
| **Obszar** | stożek |
| **Czas działania** | natychmiastowy; zob. opis |
| **Rzut obronny** | Wola neguje (ST 16, z +1 za gnomią magię) |
| **Odporność na czary** | tak |

Skutki zależą od kości wytrzymałości celu:
- 2 KW lub mniej: nieprzytomny, oślepiony i ogłuszony przez 2k4 rund, potem oślepiony i ogłuszony przez 1k4 rund, a potem ogłuszony przez rundę;
- 3–4 KW: oślepiony i ogłuszony przez 1k4 rund, potem ogłuszony przez rundę;
- 5 KW lub więcej: ogłuszony przez rundę.

*Słabsi przeciwnicy padają jak muchy. Uważaj, żeby w stożku nie stali sojusznicy.*

### Splątanie

*Nazwa w podręczniku: Entangle*

| | |
|---|---|
| **Szkoła** | przemiany |
| **Krąg** | czar linii krwi (dla zaklinacza 1. krąg) |
| **Czas rzucania** | 1 akcja standardowa |
| **Komponenty** | W, S |
| **Zasięg** | daleki |
| **Obszar** | rośliny w promieniu 40 stóp |
| **Czas działania** | 1 minuta na poziom (odw.) |
| **Rzut obronny** | Refleks częściowo (ST 15) |
| **Odporność na czary** | nie |

Rośliny oplatają wszystkich w obszarze. Kto nie zda rzutu na Refleks, zostaje unieruchomiony. Kto zda, może się poruszać, ale obszar jest dla niego trudnym terenem. Co rundę rośliny próbują ponownie.

*Pod wodą działa dziwnie, ale w atrium stoją donice z pnączami, a kanały porasta mech. Linia krwi szepcze: „zaufaj mi”.*
