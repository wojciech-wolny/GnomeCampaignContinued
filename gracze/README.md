# Materiały dla graczy

Ten folder możesz czytać przed sesją i w jej trakcie.  
**Nie zaglądaj do folderu [`../MG/`](../MG/README.md)** — są tam rozwiązania i tajemnice.

---

## Spis treści

| Plik | Zawartość |
|---|---|
| [brief.md](brief.md) | Krótkie wprowadzenie (bez zdradzania fabuły) |
| [mapa.md](mapa.md) | Orientacyjna mapa skrzydła |
| [rekwizyty.md](rekwizyty.md) | Kartki, które MG wręczy wam w trakcie gry |
| [postacie-skrot.md](postacie-skrot.md) | Pięć gotowych postaci w skrócie, do wyboru |
| [postacie/](postacie/README.md) | Pełne karty postaci (karta, czary, atuty, zdolności, historia, stan) |
| [karty-do-druku/](karty-do-druku/README.md) | Jednostronicowe karty postaci do wydrukowania |

---

## Przed sesją

1. Przeczytaj [brief.md](brief.md).
2. Wybierz postać ze [skrótu](postacie-skrot.md) albo od razu z pełnych kart.
3. Otwórz `postacie/{twoja-postać}/sheet.md`, a do śledzenia czarów i zasobów używaj `state.md`.
4. Jeśli gracie na papierze, wydrukuj plik swojej postaci z [`../druk/postacie/`](../druk/postacie/index.html).
5. Mapę i rekwizyty dostaniecie przy stole.
